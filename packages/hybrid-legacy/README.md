# @xaui/hybrid-legacy

> **Frozen.** These are the components published as `@xaui/hybrid` up to `0.0.14`,
> republished under this name while `@xaui/hybrid` is rebuilt on the v1 API. Bug fixes only.
> Pin an exact version — `pnpm add --save-exact @xaui/hybrid-legacy@0.0.14` — so an
> unattended update cannot move you off it.
>
> New projects should use [`@xaui/hybrid`](https://www.npmjs.com/package/@xaui/hybrid).

The documentation for `@xaui/hybrid-legacy` is not ready yet (“no doc yet”). In the meantime, explore the source under `packages/hybrid-legacy/src` to inspect the React/ReactDOM components, the `useXUITheme` hooks, and the `framer-motion`/`tailwindcss` integrations.

## Installation

```bash
pnpm add @xaui/hybrid-legacy
```

- `react` ^18 || ^19
- `react-dom` ^18 || ^19
- `framer-motion` ^11
